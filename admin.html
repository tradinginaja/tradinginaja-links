 Cara Menggunakan

        
Ikuti langkah-langkah berikut untuk mengelola gambar testimoni.


        


          

            
Pilih Metode Upload Gambar

            

              Opsi A — ImgBB (Direkomendasikan): Gunakan tab "Upload ImgBB" untuk hosting gambar gratis. Daftar di api.imgbb.com untuk mendapatkan API Key gratis.


              Opsi B — File di Repository: Simpan gambar di folder images/testimonials/ di repository GitHub Anda. Lalu tambahkan URL lokal di tab "Kelola Gambar".
            

          


          

            
Tambahkan Gambar

            

              Di tab "Kelola Gambar", tambahkan gambar melalui URL atau file lokal. Anda bisa menambahkan sebanyak mungkin gambar. Gambar bisa di-reorder dan dihapus.
            

          


          

            
Generate Kode

            

              Klik tombol "Generate Kode" untuk membuat isi file testimonials.js. Copy kode yang dihasilkan.
            

          


          

            
Update File di GitHub

            

              Buka repository GitHub Anda → File testimonials.js → Klik ikon edit (pensil) → Hapus semua isi lama → Paste kode baru → Klik "Commit changes".
            

          


          

            
Selesai!

            

              Website akan otomatis diperbarui dengan gambar testimoni baru. Tunggu 1-2 menit agar GitHub Pages memprosesnya.
            

          


        

      


      

        

           FAQ
        


        

          
Apakah ImgBB benar-benar gratis?

          

            Ya! ImgBB menyediakan hosting gambar gratis tanpa batas waktu. Ukuran maks per gambar 32MB.
          

        

        

          
Berapa lama gambar di ImgBB tersimpan?

          

            Gambar tersimpan selamanya (tidak ada expiry) selama akun aktif.
          

        

        

          
Bagaimana mengubah interval slide?

          

            Edit nilai SLIDE_INTERVAL di file testimonials.js. Satuan dalam milidetik (5000 = 5 detik).
